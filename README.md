# 📸 AI Camera FOV Simulator
(AI相机视场角与光学覆盖仿真工具)

## 📖 项目简介 (Introduction)
这是一个基于 **Three.js** 开发的纯前端 3D 交互式工具，专为弱电工程、安防监控部署和空间设计打造。
它可以帮助你在 3D 空间中实时模拟相机的**光学覆盖范围（FOV 视锥体）**，并精准验证视线是否被障碍物（如栏杆、墙壁）遮挡。

## ✨ 核心功能 (Features)
- **📐 纯粹几何光学推演**：根据真实的 HFOV（水平视场角）和 16:9 画幅，严格生成无物理裁剪的完美四棱锥光锥。
- **🎛️ 全动态参数调节**：
  - **空间维度**：房间长/宽/高、地毯位置。
  - **相机控制**：安装深度、高度、俯仰角（目标对焦点）、视场角大小、光锥投射距离。
  - **障碍与目标**：动态调节栏杆的高度与深度，自带 4 个 1.9m 站立人像智能跟随地毯移动。
- **🌌 科技感视觉渲染**：采用发光叠加材质（Additive Blending）呈现半透明视锥，遮挡关系一目了然。
- **🚀 零依赖 & 极速运行**：纯原生 HTML/JS/CSS 编写，单文件运行，无需任何后端支持。

## 🛠️ 使用方法 (Usage)
本项目为单文件纯静态网页，无需配置任何 Node.js 环境或构建工具：
1. 克隆或下载本仓库。
2. 将核心文件命名为 `index.html`。
3. 双击直接在浏览器中打开。
4. **视口操作**：鼠标左键旋转视角 | 右键平移 | 滚轮缩放。

## 💻 技术栈 (Tech Stack)
- HTML5 / CSS3 / Vanilla JavaScript
- [Three.js](https://threejs.org/) (r128) - 3D 渲染引擎
- OrbitControls - 3D 视角轨道控制器
